# amp - Media Player

amp is a simple media player built using C and SDL2.

*Not to confuse with [Adenosine monophosphate (AMP)](https://en.wikipedia.org/wiki/Adenosine_monophosphate).*

## Features

- Basic playback for MKV and MP4 media files
- Support for ASS and SRT subtitles
- Remember last playback position and settings for each video file
- Playback history (<kbd>Ctrl+Z</kbd> <kbd>Ctrl+Y</kbd>)
- Hardware and software decoding
- Runtime themes
- Recent files

## Dependencies

- [SDL2](https://www.libsdl.org/)
- [SDL2_ttf](https://github.com/libsdl-org/SDL_ttf)
- [FFmpeg](https://ffmpeg.org/)
- [libass](https://github.com/libass/libass)
